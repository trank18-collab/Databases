# Databases

## Create and display a playlist

Run these scripts once, in this order, in the same Oracle schema:

1. `usertable.sql`
2. `mood.sql`
3. `movietable.sql`
4. `musictable.sql`
5. `insertions.sql`
6. `playlisttable.sql`
7. `playlistsongtable.sql`

Then run `playlist.sql` in SQL*Plus. It will prompt for the playlist name,
movie ID, and music genre. For example, use:

- Playlist name: `Interstellar soundtrack`
- Movie ID: `101`
- Music genre: `Soundtrack`
